# Portfólio — Luiz Henrique

Site estático pronto para GitHub Pages, com versões em português (`index.html`) e inglês (`en/index.html`). O conteúdo combina o currículo fornecido por Luiz Henrique, os repositórios públicos do perfil [Henrique1201](https://github.com/Henrique1201) e a experiência nos projetos LIA e VIGIA do NUVEN. Os projetos do NUVEN aparecem como experiência profissional, sem links para repositórios privados; a seção de projetos reúne apenas código público. Revise textos e contatos antes da publicação. O telefone e o e-mail do currículo não foram incluídos no site.

## Publicar em `henrique1201.github.io`

1. Crie no GitHub um repositório público chamado `Henrique1201.github.io`.
2. Envie `index.html`, `styles.css`, `script.js` e a pasta `en/` para a raiz da branch `main`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
4. Acesse `https://henrique1201.github.io/` (português) ou `https://henrique1201.github.io/en/` (inglês) após a publicação.

Não há dependências nem etapa de build. O botão PT/EN alterna as páginas. Ao atualizar o conteúdo, revise as duas versões.
